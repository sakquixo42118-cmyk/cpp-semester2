在二维直角坐标系中，三个点的坐标形成一个三角形，设计一个三角形类，判断给定坐标点是否在三角形中（不包括落于三角形的边）。坐标点需用类来实现。测试主函数如下所示：

int main() {
	double x1, y1, x2, y2, x3, y3;
	double x, y;
	while (cin >> x1 >> y1) {
		cin >> x2 >> y2;
		cin >> x3 >> y3;
		cin >> x >> y;
		point a(x1, y1);
		point b(x2, y2);
		point c(x3, y3);
		point m(x, y);
		triangle t(a, b, c, m);
		if (t.judge()) {
			cout << "Yes" << endl;
		}
		else {
			cout << "No" << endl;
		}
	}
	return 0;
}
输入
输入有四行，每行两个浮点数。前三行共六个数分别代表三角形的三个顶点；最后两个数分别表示需要判断的点的坐标。

输出
若点在三角形中，输出“Yes”；否则输出“No”。

样例输入 Copy
1.00 0.00
1.50 3.50
2.73 -3.12
1.23 0.23
-1.00 0.00
1.50 3.50
2.73 -3.12
2333.33 233333.33
样例输出 Copy
Yes
No
