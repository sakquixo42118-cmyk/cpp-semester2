为了便于对时间进行处理，你需要设计一个Clock类，其内封装小时(hour)、分钟(minute)、秒(second)三个属性用来表示时间，三个属性都是int，该时间为24小时制时间，并实现常用的时间处理方法和类的运算符重载。具体来说要求如下：

1.小时、分钟、秒三个属性以及类的构造函数，自行添加其它需要的属性和函数（如果需要）；

2.实现+，++，==，<<运算符重载，+表示两个Clock对象相加，++表示second+=1，前置或者后置自增都可以；

3.需要处理时间相加和自增时产生的进位，hour>=24后重新回到0点。



测试代码如下：

int main() {

    int h1, m1, s1, h2, m2, s2;

    while (cin >> h1 >> m1 >> s1 >> h2 >> m2 >> s2) {

        Clock c1(h1, m1, s1);

        Clock c2(h2, m2, s2);

        Clock c3 = c1 + c2;

        cout << "c1 = " << c1 << endl;

        cout << "c2 = " << c2 << endl;

        cout << "c1 + c2 = " << c3 << endl;

 

        ++c1;

        cout << "++c1 = " << c1 << endl;

 

        if (c1 == c2) {

            cout << "c1 和 c2 时间相等" << endl;

        }

        else {

            cout << "c1 和 c2 时间不相等" << endl;

        }

    }

    return 0;

}




输入
两行，每行三个参数，分别对应hour,minute,second，需要考虑多组输入，测试函数中已实现。

输出
详见测试函数，注意时间的输出如果某个参数小于10需要补0
