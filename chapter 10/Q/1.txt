使用虚函数编写程序，求球体和圆柱体的体积及表面积。由于球体和圆柱体都可以看作由圆继承而来，因此，可以把圆类 Circle 作为基类。在 Circle 类中定义一个数据成员 radius 及两个虚函数 area 和 volume。由 Circle 类派生Sphere 类和 Column 类。在派生类中对虚函数 area 和 volume 重新定义，分别求球体和圆柱体的体积及表面积。 mian 函数的测试代码如下：

int main() {
	double radius, height;
	cout << "Enter the radius of the sphere: ";
	cin >> radius;
	Sphere sphere(radius);
	cout << "Enter the radius and height of the column: ";
	cin >> radius >> height;
	Column column(radius, height);
	cout << fixed << setprecision(2);
	cout << "Sphere area: " << sphere.area() << endl;
	cout << "Sphere volume: " << sphere.volume() << endl;
	cout << "Column area: " << column.area() << endl;
	cout << "Column volume: " << column.volume() << endl;
	return 0;
}
输入
程序将提示用户输入球体的半径和圆柱体的半径及高度。

输出
程序将输出球体的表面积和体积，以及圆柱体的表面积和体积。

5 
3 10
