三体人的一天由 H=24 小时，M=60 分钟，S=60 秒组成。请设计一个 Time 类，能够实现时间的自增和相加。

要求：

重载 + 运算符：实现两个 Time 对象相加，结果需自动进位并对 24 小时取模。

重载 ++ (前置) 运算符：实现时间增加 1 秒，结果需自动进位。

重载 << 运算符：以 HH:MM:SS 格式输出，不足两位补零。

主函数实现如下：

int main() {
    int h1, m1, s1, h2, m2, s2, n;
    while(cin >> h1 >> m1 >> s1 >> h2 >> m2 >> s2) {
        Time t1(h1, m1, s1), t2(h2, m2, s2);
        cout << (t1 + t2) << endl;
        cin >> n;
        while(n--) ++t1;
        cout << t1 << endl;
    }
    return 0;
}

输入
多组测试数据。

每组第一行两个时间 H1 M1 S1 和 H2 M2 S2。

第二行一个非负整数 N。

输出
输出两个时间相加后的结果。

输出第一个时间在连续执行 N 次 ++ 操作后的结果。

样例输入 Copy
10 30 50 0 40 20
20
样例输出 Copy
11:11:10
10:31:10
