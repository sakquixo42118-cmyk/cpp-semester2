实现一个 Fraction 类支持精确计算。

要求：

结果必须是最简分数；分母始终为正。

重载 +, -, * 以及 <<。

处理分子为 0 或结果为整数的情况。

主函数实现如下：

int main() {
    string s1, s2;
    while (cin >> s1 >> s2) {
        Fraction f1 = Fraction::fromStr(s1), f2 = Fraction::fromStr(s2);
        cout << f1+f2 << " "<< f1-f2 << " " << f1*f2 << endl;
    }
    return 0;
}

输入
多组测试数据输入，每组两个分数 a/b c/d。

输出
每组输出三行：加、减、乘的结果。

样例输入 Copy
1/2 1/3 
2/1 1/2
样例输出 Copy
5/6 1/6 1/6 
5/2 3/2 1
