请设计一个类模板 Matrix<T>，支持 M*N 维度的矩阵。

要求：

构造函数支持指定行数 R 和列数 C。

重载 +：实现同维度矩阵加法。

重载 *：实现矩阵乘法（左矩阵列数等于右矩阵行数）。

重载 <<：按行输出，元素间用空格分隔。

主函数实现如下：

int main() {
    int r1, c1, r2, c2;
    while(cin >> r1 >> c1) {
        Matrix<long long> a(r1, c1); a.fill();
        cin >> r2 >> c2;
        Matrix<long long> b(r2, c2); b.fill();
        if(r1 == r2 && c1 == c2) cout << a + b << endl;
        cout << a * b << endl;
    }
    return 0;
}

输入
每组数据：

矩阵 A 的行数 R1、列数 C1 及其元素。

矩阵 B 的行数 R2、列数 C2 及其元素。
注：测试确保加法时维度一致，乘法时满足 C1=R2。

输出
输出 A + B (如果维度一致) 和 A * B。如果 A + B 维度不一致，则不输出加法结果。

样例输入 Copy
2 2 1 0 0 1
2 2 1 2 3 4
样例输出 Copy
2 2
3 5
1 2
3 4
