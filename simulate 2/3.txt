设计泛型集合类并实现集合运算，支持集合的并、交、差。

要求：

1.抽象基类Setbase<T>

（1）保护成员：vector<T> elements

（2）函数：

void add(T val)：纯虚函数，添加元素

int size()：返回元素数量

（3）重载==：判断两个集合元素相等

2.模板派生类 GenericSet<T>（公有继承 Setbase<T>）

（1）实现void add(T val)：保持升序添加元素，自动去重

（2）实现bool contains(T val)：判断元素是否存在

（3）运算符重载，需要返回一个新的GenericSet<T>对象

+：并集（所有元素，去重）

*：交集（共同存在的元素）

-：差集（属于当前集合，不属于另一集合）

（4）重载<<：输出格式：{1, 2, 3, 5}，空集输出{}。

（5）添加函数：

int sum()：元素求和

int maxVal()：最大值

int minVal()：最小值
