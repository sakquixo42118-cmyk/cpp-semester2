Scuter 为了保卫家园，要和怪兽进行一对多搏斗。Scuter 和怪兽都是游戏中的角色， 两者可以派生于同一个基类 GameCharacter。各类的具体要求描述如下：

(1) GameCharacter 类有数据成员攻击力 attack 和生命值 hp。成员函数 isDeath 判断角色是否死亡。使用成员函数 getAttack 和 getHp 来获取数据。使用成员函数 setAttack 和 setHp来修改数据。带参数构造函数来初始化生命值和攻击力。

(2) Scuter 类有成员函数 leastLossOfHp 计算 Scuter 消灭给定的一组怪兽最少要损失多少的生命值。实现 Scuter 带参构造函数。

(3) 怪兽 Monster 类有成员函数 operator <运算，用于比较威胁程度。实现怪兽的无参构造函数，生命值和攻击力初始化为 0。

输入一组怪兽和一个 Scuter（给定攻击力 attack 和生命值 hp），计算 Scuter 消灭所有怪兽最少要损失多少的生命值(理论值，可以大于初始生命值)，并判断 Scuter 能否生存下去。可以思考按什么顺序击杀怪兽。

 

注：Scuter 只能单体攻击，会优先消灭威胁程度大的怪兽，题目关键在于如何计算威胁程度。怪兽和 Scuter 的攻击是同一时刻产生的，即就算怪兽在某一刻被杀死，它产生的攻击依然有效。Scuter 同理。

提示：与某只怪兽战斗时，需承担该怪兽和其它存活怪兽的一同攻击。本题的目标是最终承受伤害之和最小。

 

主函数的测试代码如下：

int main() {
	Monster* monster;
	int attack, hp, num;
	while (cin >> hp >> attack) {
		Scuter scuter(hp, attack);
		cin >> num;
		monster = new Monster[num];
		for (int i = 0; i < num; ++i) {
			cin >> hp >> attack;
			monster[i].setHp(hp);
			monster[i].setAttack(attack);
		}
		cout << scuter.leastLossOfHp(monster, num) << " ";
		if (scuter.isDeath()) {
			cout << "Dead" << endl;
		}
		else {
			cout << "Alive" << endl;
		}
		delete[] monster;
		monster = nullptr;
	}
	return 0;
}
输入
输入包含多个测试用例。每组测试用例第一行是两个整数 hp，attack，分别表示 Scuter 的生命值和攻击力。第二行输入一个整数 num，表示怪兽的数目。输入 num 行，每行两个整数，分别表示怪兽的生命值和攻击力，均大于 0。最终计算结果不会超出 int 范围。

输出
输出 Scuter 最少要损失的生命值(可能大于初始生命值)和状态，状态”Dead”表示死 亡，”Alive”表示存活。中间用空格隔开。

样例输入 Copy
100 1
3
1 10
1 20
1 40
4 10
1
7 3
样例输出 Copy
110 Dead
3 Alive
