计算公司年终奖，已知某公司年终奖体系如下：有固定的基本奖金 6000 元，根据工作业绩将员工分为 A,B,C 三类。

(1) C 类员工年终奖=基本奖金+该员工一个月的月薪。

(2) B 类员工年终奖=基本奖金+该员工三个月的月薪。

(3) A 类员工年终奖=基本奖金+该员工五个月的月薪。

实施数年发现 C 类员工大量跳槽，管理层决定缩小年终奖的差距，具体措施是首先确定 B 类员工的数量 count，B 类员工年终奖计算方式不变，然后每一 A 类员工年终奖减去 count×1000，每一位 C 类员工年终奖加上 count×1000。

假设定义员工抽象类 Employee，数据成员有序号 id、月薪 salary、基本奖金 bonus 和静态数据成员 count，构造函数初始化数据成员，纯虚函数 show()用于派生类输出员工的年终奖信息。

Employee 类派生 A、B 和 C 类，三类都用构造函数初始化数据成员，重新定义 show()。主函数的测试代码如下：

int main() {
	int id, sa;
	Employee* p;
	while (cin >> id >> sa) {
		if (id >= 1 && id <= 20) { // A 类员工
			A a(id, sa);
			p = &a;
			p->show();
		}
		else if (id >= 21 && id <= 100) { // B 类员工
			B b(id, sa);
			p = &b;
			p->show();
		}
		else if (id >= 101 && id <= 120) { // C 类员工
			C c(id, sa);
			p = &c;
			p->show();
		}
		else {
			return 0;
		}
	}
	return 0;
}
输入
输入一行序号 id 和月薪 sa。序号 1-20 视为 A 类员工，序号 21-100 视为 B 类员工，序号 101-120 视为 C 类员工。原则上先全部输入完 B 类员工信息，完成 count 的自动计数，再输入 A 类和 C 类员工的信息。示例中会先输入一个 A 类和一个 C 类员工信息，待输完 B 类员工，再输入相同的 A 类和 C 类员工信息，以便显示年终奖调整策略。

输出
每输入一行对应输出一行员工年终奖信息，输出只有 prize 前有一个空格，符号都是英文输入，输完一行自动换行。
