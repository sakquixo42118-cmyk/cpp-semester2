设有两行按升序排列的二进制数据，每八位表示一个数字，将它们合并生成一串新的二进制数据。

例如：

0000000000000010表示00000000=0，00000010=2

0000000100000011表示00000001=1，00000011=3

按0 1 2 3的顺序排序拼接二进制串00000000+00000001+00000010+00000011

所以最终结果为：00000000000000010000001000000011

以下为main函数，请补充完整：

int main() {
    string line1, line2;
    while (getline(cin, line1) && getline(cin, line2)) {
        string merged = mergeBinary(line1, line2);
        cout << merged << endl;
    }
    return 0;
}
输入
每组输入为两行，每行为一串二进制数。

输出
输出合并后的数串，将二进制数按大小顺序排列拼接即可。

样例输入 Copy
0000000000000010
0000000100000011
0000000011110000
000000010000001000000100
样例输出 Copy
00000000000000010000001000000011
0000000000000001000000100000010011110000
