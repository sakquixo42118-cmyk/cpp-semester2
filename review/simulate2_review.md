# simulate 2 复习整理

> 说明：当前线程里没有可读取的更早聊天记录，所以“之前问过的问题”这一部分我无法直接还原；本文件主要依据 `simulate 2/Q` 的 12 道题面、对应 cpp，以及代码中的注释/提醒整理。

## 总体高频考点

- 面向对象：抽象基类、纯虚函数、继承、多态、基类引用/指针调用派生类函数。
- 运算符重载：`+`、`-`、`*`、`<`、`==`、`!=`、`<<`、前置 `++`。
- 模板类：`template <typename T>`、模板继承、基类成员访问、返回模板对象。
- STL：`vector`、二维 `vector`、`sort`、`stringstream`、`getline`、`erase`、`push_back`。
- 输入输出格式：`setw`、`setfill`、`fixed`、`setprecision`、`boolalpha`、括号/逗号/空格。
- 边界情况：负数、分母为负、空集合/空库存、结果为 0、整数结果、并列比较、跨 60/24 进位。

## 第 1 题：角色战斗 Character / Warrior / Mage

考点：抽象基类、纯虚函数、继承、多态、对象状态修改。

易错点：
- `attack(Character& target)` 要传引用，才能直接修改目标 `hp`。
- `0.1 * hp` 和 `1.5 * atk` 要向下取整，可用 `int(...)`。
- 先战士攻击法师，再法师攻击战士；即使法师被打到 `hp <= 0`，给定 main 仍然会继续执行法师攻击。
- `isDead()` 判断条件是 `hp <= 0`，不是 `hp == 0`。

## 第 2 题：棒球比赛计分 calPoints

考点：栈思想、字符串解析、`vector<int>`、`stoi`、`getline + stringstream`。

你注释里的错点：
- 不能直接用简单的 `isdigit` 判断所有数字，因为要考虑负数和多位数。
- `stoi()` 很好用，要记住。
- 一整行输入需要 `getline`，再用 `stringstream` 按空格切分，需要 `#include <sstream>`。

复习提醒：
- `"C"`：删除上一次有效分数，`pop_back()`。
- `"D"`：加入上一分数的两倍。
- `"+"`：加入前两次有效分数之和。
- 整数字符串包括 `"10"`、`"-2"`，建议统一用“不是 `+`/`D`/`C` 就 `stoi`”处理。

## 第 3 题：泛型集合 GenericSet

考点：模板抽象基类、模板继承、去重、排序、集合并交差、输出重载。

你注释里的错点：
- `class GenericSet: public Setbase<T>` 里必须写 `<T>`。
- 模板派生类访问基类模板成员时，要用 `using Setbase<T>::elements;`，或写 `this->elements`。
- 调用函数要带括号，如 `bubble()`。
- 添加第一个元素后可以直接 `return`，避免后续逻辑重复处理。

复习提醒：
- `add` 要做到“去重 + 升序”。
- `operator==` 要比较大小和每个元素；因为集合已排序，顺序比较可行。
- `operator+` 用 `add` 合并两个集合，自动去重。
- `operator*` 找共同元素。
- `operator-` 找只在左集合里的元素。
- 输出格式是 `{1, 2, 3}`，空集合是 `{}`。

## 第 4 题：Time 时间类

考点：运算符重载、前置 `++`、时间进位、格式化输出。

你注释里的错点：
- `setw(2) << setfill('0')` 这种格式化表达要记住。

复习提醒：
- 秒满 60 进分钟，分钟满 60 进小时，小时对 24 取模。
- 前置 `++` 的返回类型通常写 `Time&`，最后 `return *this;`。
- `operator<<` 里不要忘记补零输出 `HH:MM:SS`。

## 第 5 题：Fraction 分数类

考点：静态工厂函数、字符串解析、分数加减乘、约分、符号规范。

你注释里的错点：
- `fromStr` 可做成 `static`，这样无需已有对象就能调用 `Fraction::fromStr(s)`。
- 分母为负时，要把负号移动到分子上，保证分母始终为正。
- 约分时分子可能为负，判断整除要对分子用 `abs(nson)`。

复习提醒：
- 结果为 0 输出 `"0"`。
- 结果能整除时输出整数，如 `1`，不要输出 `1/1`。
- 更稳的约分方式是用 `gcd(abs(son), mom)`，比循环试除更可靠。

## 第 6 题：Matrix<T> 矩阵模板

考点：二维 `vector`、模板类、矩阵加法、矩阵乘法、输出重载。

你注释里的错点：
- 二维 vector 写法：`vector<vector<T>> ma`。
- 构造函数初始化二维矩阵：`ma(a, vector<T>(b))`，括号和位置不要写错。
- 用已有二维数组构造矩阵时，也要给 `row` 和 `col` 赋值。

复习提醒：
- 加法：同位置元素相加。
- 乘法：`out[i][j] = sum(a[i][p] * b[p][j])`。
- 当前代码里乘法临时变量写成 `int temp=0`，如果模板用 `long long` 或更大数据，可能溢出；建议写 `T temp = 0`。
- `operator<<` 里应使用传入的 `out`，不要混用 `cout`。

## 第 7 题：StringCounter 连续字符压缩

考点：字符串遍历、连续段统计、类封装。

你注释里的错点：
- 要先看清题目要求，不要拿到题就直接套别的字符串处理方法。

复习提醒：
- 统计的是“连续相同字符”的数量，不是全局出现次数。
- 每段记录一次字符和数量，例如 `aaabbc -> a3b2c1`。
- 单字符也要输出次数，如 `S -> S1`。

## 第 8 题：CPU / IO 任务调度

考点：抽象类、多态指针、派生类、`sort` 自定义比较函数。

你注释里的错点：
- `sort` 需要 `#include <algorithm>`。
- `cmp(a, b)` 返回的是“a 是否应该排在 b 前面”。
- 如果两者优先级和耗时都相同，比较函数应返回 `false`，否则可能破坏排序规则。

复习提醒：
- 排序第一关键字：`priority` 降序。
- 排序第二关键字：`getTime()` 升序。
- `CPUTask` 耗时为 `cycles / 10`，`IOTask` 耗时为 `size / 5`。
- 用 `new` 后严格来说应 `delete`，虽然题目 main 里只 `clear()`，考试通常主要看功能。

## 第 9 题：Inventory 泛型库存

考点：模板继承、商品类、库存增删查改、排序、格式化输出、默认对象。

你注释里的错点：
- `Product` 自己也需要重载 `==`，否则库存比较无法判断内容相等。
- `operator!=` 可以复用 `operator==`：`return !(*this == o);`。
- 抽象类参数不要按值传，比较函数应传引用；模板类型别忘了 `<T>`。
- 入库已有商品时数量要累加 `x.count`，不是简单 `++`。
- `erase(items.begin() + index)` 中 `index` 不要多加 1。
- 输出格式中间有逗号和空格；不要给每个商品外面再重复包整体括号；最后别忘记补 `]`。

复习提醒：
- `IN`：同名商品累加数量并更新价格；新商品按 `name` 字典序插入。
- `OUT`：不存在或库存不足返回 `false`；否则扣减，扣到 0 删除并返回 `true`。
- `MAX`：库存数量最大；并列时名字字典序更小。
- 空库存的 `MAX` 返回默认商品：`(,0.00,0)`。
- `VALUE` 和商品输出都要保留两位小数。

## 第 10 题：Item 背包物品

考点：构造函数默认值、`+`、`<`、`<<` 重载、最大值选择。

复习提醒：
- `operator+` 返回新 `Item("Total", weight + b.weight, value + b.value)`。
- `operator<` 按 `value` 比较，用于找价值最高物品。
- `Item best;` 需要默认构造函数，因此构造函数参数要给默认值。
- 输出格式：`name weight value`，不要额外括号或逗号。

## 第 11 题：Polynomial 多项式

考点：数组/向量存系数、常数项到最高项、函数求值。

复习提醒：
- 输入系数顺序是从常数项开始：`coef[i]` 对应 `x^i`。
- `print()` 输出所有系数，空格格式要贴合样例。
- 当前代码用 `pow(x, i)`，`pow` 返回浮点数；整数多项式更推荐迭代累乘或 Horner 法，避免精度问题。
- 当前返回类型是 `long long unsigned int`，如果系数或结果可能为负，会出错；更稳妥是 `long long`。

## 第 12 题：Car 费用比较

考点：类封装、成员函数、费用公式、比较函数。

题目要求：
- `费用 = distance * costPerKm + baseCost`。
- 如果两辆车费用相同，输出第一辆。

当前代码仍可能扣分的点：
- `isCheaperThan` 现在写的是 `<`，但题面要求“小于等于”，相等时应该返回 `true`。
- 应改为：`return getCost(dis) <= o.getCost(dis);`

复习提醒：
- `getCost(double distance)` 不要漏加基础费用。
- main 中根据 `isCheaperThan` 选择输出，所以并列规则必须放在这个函数里。

## 考前速记

- 模板派生类访问基类成员：`using Base<T>::x;` 或 `this->x`。
- 输入一整行再拆分：`getline(cin, line); stringstream ss(line); while (ss >> s) ...`
- 排序比较函数：严格表达“a 是否排在 b 前”，完全相等返回 `false`。
- 输出重载：函数签名常用 `friend ostream& operator<<(ostream& out, const T& x)`，内部尽量只用 `out`。
- 负数/多位数解析：优先 `stoi`，不要只看第一个字符是不是数字。
- 分数、时间、矩阵、库存这类题，最容易错在格式和边界，不要只看主逻辑。
