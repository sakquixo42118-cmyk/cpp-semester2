编写一个模板类，该类包含一个向量成员，提供一个成员函数用于计算向量中所有元素的和。main函数的测试代码如下：

int main() {
	int n;
	while (cin >> n) {
		vector<int> vec(n);
		for (int i = 0; i < n; ++i) {
			cin >> vec[i];
		}
		VectorSum<int> vs(vec);
		cout << vs.computeSum() << endl;
	}
	return 0;
}
输入
输入包含多组数据，每组数据由两行组成。第一行是一个整数n，表示向量的大小；第二行包含n 个整数，表示向量的元素。
输出
对于每组输入数据，输出该向量中所有元素的和。

必须使用的关键字
template 
样例输入 Copy
3 
1 2 3 
4 
1 2 3 4
样例输出 Copy
6 
10
