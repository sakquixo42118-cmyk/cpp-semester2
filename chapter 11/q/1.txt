编写一个模板类，该类包含一个向量成员。提供一个成员函数用于在已排序的向量中进行二分查找，并返回元素的位置，如果未找到则返回-1。main函数的测试代码如下：

int main() {
	int n;
	while (cin >> n) {
		vector<int> vec(n);
		for (int i = 0; i < n; ++i) {
			cin >> vec[i];
		}
		int target;
		cin >> target;
		SortedVector<int> sv(vec);
		int result = sv.binarySearch(target);
		cout << result << endl;
	}
	return 0;
}
输入
输入包含多组数据，每组数据由三行组成。第一行是一个整数n，表示向量的大小；第二行包含n 个整数，表示向量的元素；第三行是一个整数x，表示要查找的元素。

输出
对于每组输入数据，输出元素的位置。
必须使用的关键字
template 
样例输入 Copy
5
1 2 3 4 5
3
样例输出 Copy
2
