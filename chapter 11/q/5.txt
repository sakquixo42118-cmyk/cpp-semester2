编写一个模板类，该类包含一个字符串成员。提供一个成员函数用于加密字符串，加密规则是将每个字符的 ASCII 码值加 3。main函数的测试代码如下：

int main() {
	string line;
	while (getline(cin, line)) {
		EncryptedString<char> es(line);
		es.encrypt();
		cout << es.getString() << endl;
	}
	return 0;
}
输入
输入包含多组数据，每组数据是一行字符串。

输出
对于每组输入数据，输出加密后的字符串。

必须使用的关键字
template 
样例输入 Copy
hello
样例输出 Copy
khoor
