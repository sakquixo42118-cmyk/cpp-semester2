编写一个函数模板，该函数接受一个向量参数，并返回一个新的向量，新向量中的元素是原向量元素的乘积。main函数的测试代码如下：

int main() {
	int n;
	while (cin >> n) {
		vector<int> vec(n);
		for (int i = 0; i < n; ++i) {
			cin >> vec[i];
		}
// 函数模板vector<T> computeProductVector(const vector<T>& input)
		auto result = computeProductVector(vec);
		for (size_t i = 0; i < result.size(); ++i) {
			if (i > 0) cout << " ";
			cout << result[i];
		}
		cout << endl;
	}
	return 0;
}
输入
输入包含多组数据，每组数据由两行组成。第一行是一个整数n，表示向量的大小；第二行包含n 个整数，表示向量的元素。

输出
对于每组输入数据，输出新向量中的元素。

必须使用的关键字
template

3
1 2 3
样例输出 Copy
6
