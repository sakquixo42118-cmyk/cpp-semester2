编写一个模板类，该类包含一个向量成员。提供一个成员函数用于过滤向量中的元素，只保留满足特定条件的元素，并返回过滤后的向量。main函数的测试代码如下：

int main() {
	int n;
	while (cin >> n) {
		vector<int> vec(n); 
		for (int i = 0; i < n; ++i) {
			cin >> vec[i];
		}
		int k;
		cin >> k; 
		FilteredVector<int> fv(vec);
		auto filtered = fv.filterGreaterEqual(k);
		for (size_t i = 0; i < filtered.size(); ++i) {
			if (i > 0) {
				cout << " "; 
			}
			cout << filtered[i];
		}
		cout << endl;
	}
	return 0;
}
输入
输入包含多组数据，每组数据由三行组成。第一行是一个整数n，表示向量的大小；第二行包含n 个整数，表示向量的元素；第三行是一个整数k，表示过滤条件。

输出
对于每组输入数据，输出过滤后（≥k）的向量元素。

必须使用的关键字
template 
样例输入 Copy
5 
1 2 3 4 5
3
样例输出 Copy
3 4 5
